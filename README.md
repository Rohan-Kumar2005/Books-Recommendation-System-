# BOOk RECOMMENDATION SYSTEM

This is a Collaborative Filtering -based Book Recommendation system built usig python and streamlit

## Features
-> Select your favorite book from an interactive dropdown menu.
-> Get top similar book recommendation with a single click
-> User-friendly web interface powered by streamlit.

## Technologies Used
-> python 
-> pandas & numpy
-> scikit-learn (cosine similarity)
-> streamlit(web app UI)
